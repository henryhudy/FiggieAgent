\begin{abstract}
Deep counterfactual regret minimization (Deep CFR) replaces the information-set tables of counterfactual regret minimization with neural networks. This can be useful when tables are too large, but it also introduces approximation error. We study that trade-off in Figgie-Lite, a two-player zero-sum trading reduction with four hidden goal-suit worlds, private cards, public buy outcomes, and an exact exploitability evaluator. The central intervention is an exact Bayesian card-consistency feature. At each information set it conditions on the player's private hand and on all observed card-transfer outcomes, but it does not assume an opponent action model. We compare Deep CFR with and without this feature, as well as tabular CFR, across five fixed seeds after 2,000 iterations. Exact exploitability is $5.549 \pm 0.364$ for Bayesian Deep CFR, $5.413 \pm 0.404$ without the feature, and $1.090 \pm 0.030$ for tabular CFR. The feature does not improve this small benchmark at the tested budget. The result is a bounded negative finding: exact state evidence alone does not remove the optimization cost of neural regret approximation when the tabular problem is still small.
\end{abstract}

\section{Introduction}

Learning in imperfect-information games requires an agent to act with incomplete knowledge of the state. Counterfactual regret minimization (CFR) provides a principled tabular method for two-player zero-sum games, while Deep CFR replaces tables with learned value and strategy approximators \citep{zinkevich2007regret,brown2019deepcfr}. A common intuition is that a more explicit representation of hidden-state evidence should make the neural problem easier. This report tests that intuition in a setting where the evidence and the final policy quality can both be checked exactly.

Figgie is a market-themed card game created by Jane Street \citep{figgierules}. Its full form is multiplayer and general-sum, so standard two-player exploitability is not the appropriate evaluation target. We instead use Figgie-Lite, a deliberately small two-player zero-sum reduction. The reduction retains a hidden goal suit, private hands, public action outcomes, and card transfers, while making exact evaluation feasible.

Our question is narrow: \emph{does an exact posterior over card-consistent hidden worlds help Deep CFR in Figgie-Lite?} We add the posterior as an input feature, compare it with a no-posterior network of the same architecture, and report a tabular CFR reference. We find no advantage at this scale. This is informative precisely because the measurement is exact: the posterior is a correct representation of the card evidence, yet it does not make the neural approximation competitive with the table.

\section{Related work}

CFR minimizes counterfactual regret in extensive games with imperfect information \citep{zinkevich2007regret}. Monte Carlo CFR uses sampled traversals, including external sampling, to make those updates practical \citep{lanctot2009mccfr}. Deep CFR uses neural advantage networks and replay memories in place of tabular regret and average-strategy representations \citep{brown2019deepcfr}. These methods motivate the implementation here, but the original Deep CFR results do not imply that function approximation should help in every small game.

\section{Figgie-Lite and exact card evidence}

Figgie-Lite has two players and four possible goal suits. Conditional on goal suit $g$, the deck contains three cards of suit $g$ and one card of each other suit. Each player receives three cards. At each of two ticks, both players choose \textsc{Pass} or \textsc{Buy}$(s)$ for one of four suits. A successful buy transfers one card at a fixed price. The action and its success flag are public. At settlement, payoff is the difference between each player's cash plus ten times the number of goal-suit cards held.

The game is zero-sum, so we can enumerate every chance world and compatible deal to compute exploitability exactly. It is not a model of the full Figgie market, and the results below do not establish an equilibrium guarantee for the full game.

Let $h_0$ denote the player's initial private hand and let $r_{1:t}$ denote the public action and buy-outcome records through tick $t$. For every candidate goal suit, we reconstruct the other opening hand from the candidate deck and replay the public transfers. The feature is
\[
P(g \mid h_0, r_{1:t}) \propto
P(g)P(h_0 \mid g)
\mathbb{I}\{\text{$r_{1:t}$ is card-consistent with $g$ and $h_0$}\}.
\]
The indicator makes this calculation exact for card constraints and public transfer outcomes. The actions identify which transfers to replay, but no likelihood is assigned to an opponent selecting one action over another. Thus the feature is not a posterior over strategic behavior. The full public record remains in the neural input, allowing the network to learn behavioral patterns if they are useful.

\section{Deep CFR and ablation}

We implement an external-sampling Deep CFR learner. Each player has a two-hidden-layer ReLU advantage network. Positive predicted advantages are normalized by regret matching. One traversal per player is run at every iteration: the traversing player enumerates actions and the opponent action is sampled. Advantage targets enter bounded reservoir memories; visited behavior strategies, weighted by the traverser's reach, enter a separate reservoir. The final strategy network is trained by weighted cross-entropy. All final policies are scored by the exact evaluator, not by sampled self-play.

The Bayesian network receives four current private card counts, four posterior probabilities, a two-element player indicator, and a fixed-width public-history encoding. The no-posterior ablation removes only the four posterior values. It retains the private cards, player indicator, actions, and buy-success flags, so the comparison isolates the explicit card-evidence feature rather than withholding public information.

\section{Experiment}

We train three methods for 2,000 iterations at a two-tick horizon: tabular chance-sampled CFR, Deep CFR with card-consistency posterior, and Deep CFR without it. The five fixed seeds are $\{3,7,11,19,23\}$. Both neural variants use two 64-unit hidden layers, a 20,000-item memory cap, Adam at $2\times10^{-3}$, a batch size of 128, advantage updates every 25 iterations with 25 optimization steps, and 240 final strategy-fitting steps. Table~\ref{tab:main-result} reports total exploitability $\varepsilon_0+\varepsilon_1$ in payoff units. Lower is better. \section{Results and limitations}

The explicit card-consistency posterior does not improve the neural result at this training budget. It lowers exploitability for seed 3 but is higher in the other four seeds, with a mean increase of 0.136 payoff units relative to the no-posterior network. Both neural variants remain substantially more exploitable than tabular CFR. The main conclusion is not that Bayesian state evidence is unhelpful in general. It is that, in this small reduction, correct card evidence alone does not compensate for the optimization and approximation error introduced by neural regret models.

The experiment is deliberately limited. It uses a two-tick game, five fixed seeds, a single network size, and one training budget. It does not test larger games where table sizes are prohibitive, alternative encodings, learned behavior likelihoods, or richer neural architectures. A stronger follow-up would sweep horizon and memory size, measure posterior calibration separately, and preregister the ablation before training. The study therefore supports a narrow reproducibility claim, not a claim that it measures broad reasoning or that it predicts performance in full Figgie.
